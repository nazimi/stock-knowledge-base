> 创建日期：2026年8月31日
> 目标：构建一个网页形式的个人股市知识库，包含基础金融概念、周期趋势框架、每日研报精选和低估值/顺周期推荐

| 项目 | 说明 |
|------|------|
| **名称** | 个人股市知识库 |

## 三、页面结构

### 整体布局

- **顶部栏**：标题 + 搜索框 + 更新日期
- **侧边导航**：四大模块 + 子章节，可展开折叠
- **主内容区**：四大模块内容
- **底部栏**：免责声明 + 更新时间 + 数据来源

### 四大模块

1. **基础金融概念库** — 静态知识，含 Tab 切换
   - 股票市场基础（交易制度/指数体系/资金面）
   - 估值方法论（PE/PB/PS/DCF/分位值）
   - 财务分析基础（三大报表/核心指标/造假识别）
   - 技术分析基础（均线/量价/形态）
   - 投资策略（价值/趋势/顺周期/逆周期）

2. **周期趋势框架** — 核心模块
   - 美林投资时钟（四阶段 + 受益行业）
   - 中国特色周期因素（政策/货币/地产/出口/产业升级）
   - 顺周期操作指南（决策流程 + 行业分类表）
   - 行业周期分析范例（军工行业报告）

3. **每日研报精选** — 动态更新
   - 宏观策略 / 行业分析 / 个股研究
   - 研报卡片形式，按分类筛选

4. **低估值/顺周期推荐** — 动态更新
   - 低估值筛选表（PE/PB分位值排序）
   - 顺周期定位（当前周期阶段判断）
   - 综合推荐

## 六、每日更新机制

### 更新内容

| 更新项 | 频率 | 数据来源 |
|--------|------|---------|
| 每日研报精选 | 每日 | 券商公开研报 + 市场资讯 |
| 低估值筛选表 | 每日 | finance-data 插件获取行业估值 |
| 顺周期定位 | 每日 | 宏观数据（PMI/CPI/社融/LPR等） |
| 综合推荐 | 每日 | 综合以上分析 |
| 静态知识库 | 按需 | 不定期补充 |

### 更新流程

1. Agent 获取最新宏观数据
2. Agent 获取行业估值数据
3. Agent 获取最新研报信息
4. Agent 分析当前周期阶段
5. Agent 筛选低估值板块
6. Agent 整理综合推荐
7. Agent 生成 JSON 数据块
8. 替换网页中的数据区域

---

## 七、Agent 使用指南

Agent 每日更新时的操作步骤：

1. 读取 `src/index.html` 中的 `<!-- DAILY_DATA_START -->` 到 `<!-- DAILY_DATA_END -->` 之间的 JSON 数据块
2. 获取最新市场数据，生成新的 JSON
3. 替换该数据块
4. 更新页面显示的日期

数据块格式参见 `docs/design-spec.md` 中的定义。
